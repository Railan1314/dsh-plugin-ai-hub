# 这个插件是怎么来的

一开始只是想写个“进程守护”，让免费 AI 帮忙写模组：看着流水线跑，掉线就拉起来，尽量不花付费 token。

后来发现效率不够——免费池要排队、会话会膨胀、不同任务抢同一批 key，单靠一个守护脚本管不住。于是把守护逻辑做成了 DSH 插件，能看到任务、批次、并发和 token。

再往后，原本想直接做模组内容，但发现调度器本身更通用，也更容易维护，于是把两件事拆开：

- `ai-hub`：调度台，负责任务、并发、免费池、工具接口
- `task-mod`：模组控制台，负责地图、贴图、平衡的具体工序

拆开的好处是：不需要模组的人只装调度台；需要模组的人再加 DLC。两个插件可以独立升级，出问题也更容易定位。
